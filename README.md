# 数当てゲーム（Number Guessing Game）

このプログラムは、ユーザーが指定した範囲 **n ～ m** の中からランダムに生成された数値を当てるシンプルなゲームです。  

---

## 🎮 ゲームの流れ

1. 乱数の最小値 **n** を入力  
2. 乱数の最大値 **m** を入力  
3. プログラムが **n ～ m の範囲でランダムな整数を生成**  
4. ユーザーが数値を入力し、正解するまで繰り返す  
5. 正解するとゲーム終了

---

## 🧩 使用方法

### 1. Python を実行できる環境を用意  
Python 3.12.3 が必要です。

### 2. プログラムを実行  
ターミナルで以下を実行：

```bash
python3 Guess_the_number_game.py
